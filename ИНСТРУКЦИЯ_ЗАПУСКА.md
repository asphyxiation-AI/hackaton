## Ручной запуск

### Шаг 1 — Запустить Ollama сервер

Если Ollama ещё не запущен:
```powershell
Start-Process ollama -ArgumentList "serve" -WindowStyle Hidden
```
Проверка: `ollama list` — должно показать модель `qwen2.5:7b`.

Если модели нет — скачайте:
```powershell
ollama pull qwen2.5:7b
```

### Шаг 2 — Проверить настройки LLM

Файл `.env` в корне проекта уже настроен на Ollama:
```
LLM_PROVIDER=openai
OPENAI_API_KEY=ollama
OPENAI_BASE_URL=http://localhost:11434/v1
MODEL_NAME=qwen2.5:7b
```
Менять ничего не нужно.

### Шаг 3 — Запустить Streamlit

```powershell
cd d:\admin\Dowloads\учеба\VS_Project\prototip
.\venv\Scripts\Activate.ps1
streamlit run app.py
```

Приложение будет доступно по адресу **http://localhost:8501**.

## 🖥 Как пользоваться приложением

### Режим 1 — Локальный файл (xlsx)
1. Загрузите файл датасета (`.xlsx`) или используйте автоматический (`data/raw/`).
2. Выберите аудиторию/лист:
   - **Dataset 1 (тех. специалистам)** — для ИБ-аналитиков (атаки, уязвимости, новости TG).
   - **Dataset 2 (рук-во и работники)** — для руководства (события с тегами рисков).
3. Отметьте интересы/теги для фильтрации.
4. Просмотрите таблицу ранжированных публикаций.
5. Нажмите **«Сформировать дайджест»** — запрос уйдёт к локальной модели `qwen2.5:7b`.
6. Готовый дайджест можно скачать в `.md` или `.docx`.

### Режим 2 — Сбор из источников (RSS / HTML) ← НОВОЕ
1. Выберите режим **«Сбор из источников (RSS / HTML)**».
2. В поле «URL источников» укажите адреса сайтов (по одному на строке). По умолчанию уже подставлены источники из ИНФО-листа датасета (ria.ru, securitylab.ru, xakep.ru, cisoclub.ru, kommersant.ru, anti-malware.ru, tadviser.ru и другие).
3. Нажмите **«Собрать новости»** — для каждого URL пробуется RSS, при отсутствии — парсинг HTML.
4. Выберите аудиторию, отметьте интересы, просмотрите собранные статьи.
5. Нажмите **«Сформировать дайджест»** — получите краткую сводку в формате:

   ```
   1) Что известно про хакерскую атаку на «Аэрофлот»?
   2) 28 июля «Аэрофлот» отменил около 50 рейсов из-за хакерской атаки...
   3) https://cisoclub.ru/..., https://www.anti-malware.ru/...
   ```

## 🆕 Новый модуль: `src/collectors.py`

Отвечает за сбор свежих новостей из внешних источников.

- **`fetch_rss(url, limit)`** — забирает новости из RSS-ленты (feedparser).
- **`fetch_html(url, limit)`** — резервный парсинг HTML-страницы (requests + BeautifulSoup).
- **`collect_source(url, limit)`** — пробует RSS, при неудаче — HTML.
- **`collect_all(sources, limit_per_source)`** — собирает новости из списка URL.
- **`DEFAULT_SOURCES`** — список источников из ИНФО-листа датасета.

Возвращаемые статьи имеют те же поля, что и записи из Excel (`id`, `category`, `priority`, `title`, `expected_output`, `date`, `source`, `link`), поэтому попадают в тот же конвейер ранжирования и генерации дайджеста.

## 🔍 Полезные команды Ollama

```powershell
# Список загруженных моделей
ollama list

# Запустить сервер (если не запущен)
ollama serve

# Проверить, что сервер отвечает
Invoke-RestMethod http://localhost:11434/api/tags

# Остановить все модели (выгрузить из памяти)
ollama stop qwen2.5:7b

# Удалить модель
ollama rm qwen2.5:7b
```

## ⚠️ Возможные проблемы

| Проблема | Решение |
|----------|---------|
| `Не удается соединиться с удаленным сервером` (Ollama) | Запустите `ollama serve` или перезапустите приложение Ollama из меню Пуск |
| Модель `qwen2.5:7b` не найдена | Выполните `ollama pull qwen2.5:7b` |
| Streamlit не открывается | Проверьте, что виртуальное окружение активировано: `.\venv\Scripts\Activate.ps1` |
| Ошибка LLM при генерации | Убедитесь, что Ollama сервер запущен и модель загружена (`ollama ps`) |
| Не собираются новости | Проверьте интернет-соединение и корректность URL; некоторые сайты блокируют парсинг HTML |
