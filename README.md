# ИИ-ассистент для энергетики: ИТ/ИБ-дайджесты

## Назначение

Веб-сервис для сбора, фильтрации и формирования ИТ/ИБ-дайджестов для
энергетической отрасли и объектов КИИ. На входе — датасет публикаций об атаках,
уязвимостях и событиях ИБ (xlsx); на выходе — персонализированные дайджесты
в Markdown и DOCX для двух аудиторий. Ранжирование публикаций выполняется по
ключевым интересам пользователя и приоритетам, заданным правилами ИНФО-листов.

## Архитектура

Код разделён на независимые модули; верхний слой (Streamlit) не содержит бизнес-логики.

```
app.py                 Точка входа: UI Streamlit. Загрузка датасета (upload или
                       автопоиск в data/raw/), выбор аудитории, интересы, таблица
                       ранжированных публикаций, генерация дайджеста и скачивание.

src/parser.py          Универсальное чтение файлов xlsx/docx/txt (по расширению).
src/processor.py       Парсинг листов датасета по фактическим заголовкам
                       (Dataset 1 / Dataset 2), правила приоритетов ИНФО,
                       расчёт релевантности (score 0.0–1.0) и сортировка.

src/llm.py             LLMClient: тонкая обёртка над OpenAI-совместимым API.
                       Провайдер и модель задаются через .env или аргументы.

src/generator.py       Сборка батч-запроса к LLM и генерация Markdown-дайджеста
                       под выбранную персону (system-промпт из config/prompts.py).

src/exporter.py        Сохранение дайджеста в .md и рендеринг .docx
                       (заголовки, жирный текст, списки) через python-docx.

config/prompts.py      Системные промпты: общий, JSON, технический и управленческий.
data/raw/              Входные файлы (готовый файл датасета или загруженные).
data/output/           Сгенерированные дайджесты (md/docx) и образцы.
```

**Поток данных**: `app.py` → `parse_dataset` → `filter_and_rank_articles`
(score + приоритет) → `generate_digest` (батч-запрос к `LLMClient.complete`)
→ `export_to_markdown` / `export_to_docx` → `data/output/` + кнопки скачивания.

## LLM-слой и смена провайдера

`LLMClient` работает с любым API, реализующим OpenAI-контракт
(`POST /chat/completions`), поэтому смена провайдера сводится к правке трёх
переменных в `.env` — код не изменяется:

| Провайдер        | Пример `OPENAI_BASE_URL`                          | `MODEL_NAME` (пример)  |
|------------------|---------------------------------------------------|------------------------|
| OpenAI           | `https://api.openai.com/v1`                       | `gpt-oss-120b`         |
| Qwen3 (DashScope)| `https://dashscope.aliyuncs.com/compatible-mode/v1` | `qwen3-...`          |
| Alice AI ART     | URL OpenAI-совместимого шлюза `/v1`               | модель из каталога     |
| YandexGPT        | URL совместимого шлюза `/v1`                      | модель из каталога     |

Точные идентификаторы моделей зависят от каталога провайдера; значения
проставляются в `.env`. Ответ генерируется одним батч-запросом: список
публикаций сериализуется (метаданные + текст) и отправляется с system-промптом
выбранной персоны.

## Персоны

**Технические специалисты (Dataset 1).** Вход — атаки, уязвимости, новости TG.
Дайджест форматирует каждую публикацию в структурированный список атрибутов:
для атак — страна, группировка, дата, отрасли, метод первоначального доступа,
инструменты, CVE, IoC; для уязвимостей — ПО, сервис, описание, патчи, временные
решения, наличие эксплойта, CVE, CVSS, метрики, последствия. Приоритет присваивается
по правилам ИНФО: Атака (РФ + энергетика/другие сектора/не РФ), Уязвимость
(есть эксплойт/нет), Инфо (новости TG).

**Руководство и топ-менеджмент (Dataset 2).** Вход — события, размеченные тегами
(В РФ/Вне РФ, финансовые потери, КИИ, энергетика, госсектор, регуляторы).
Дайджест представляет каждое событие в формате: заголовок; краткое описание
в 3–4 строки с акцентом на риски для КИИ, влияние на энергетику, финансовые и
юридические последствия, упоминания регуляторов; ссылки на источники.

## Запуск

```bash
python -m venv venv
venv\Scripts\activate        # Windows
source venv/bin/activate     # Linux / macOS

pip install -r requirements.txt
copy .env.example .env       # Windows
cp .env.example .env         # Linux / macOS; укажите ключ и URL провайдера

streamlit run app.py
```

Датасет помещается в `data/raw/Датасет с примерами_v4.0.xlsx` (обнаруживается
автоматически) либо загружается через интерфейс. После запуска: выбрать аудиторию,
отметить интересы, просмотреть ранжированную таблицу, сформировать дайджест и
скачать его в `.md`/`.docx` (кнопки в блоке «Дайджест»).

## Ограничения и развитие

Ограничения текущей версии:
- ранжирование по подстроковому совпадению ключевых слов — без учёта семантики;
- источник данных — статический файл, онлайн-сбор не реализован;
- качество дайджеста ограничено моделью: возможны вставки-галлюцинации
  (сдерживаются промптами «не добавляй от себя»);
- при большом корпусе возможен упор в лимит токенов — текст статьи
  сериализуется до 400 символов.

Направления развития:
- сбор публикаций через Telegram API и RSS-фиды с планировщиком обновлений;
- Hybrid RAG: векторный индекс для семантического поиска в связке с ключевым
  ранжированием и дедупликацией повторов;
- автоматическая рассылка дайджестов (SMTP/Telegram Bot), экспорт в PDF,
  мониторинг метрик качества генерации.
